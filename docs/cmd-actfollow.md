# /actfollow

## Syntax

<!--cmd-syntax-start-->
```eqcommand
/actfollow JohnDoe
/actfollow 123
/actfollow pause
/actfollow resume
/actfollow off
/actfollow ui
```
<!--cmd-syntax-end-->

## Description

<!--cmd-desc-start-->
This plugin allows you to follow a player movement more precisely using MQ actors. Both the follower and the player being followed must run the plugin.
<!--cmd-desc-end-->

## Options

`JohnDoe`
:   follow by pc name

`123`
:   follow by pc spawn id

`pause`

`resume`

`off`

`ui`
:   toggles ui
